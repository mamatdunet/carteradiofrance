# Puis-je capter la nouvelle version numérique de Radio France ?

Page web autonome : saisissez votre adresse et votre étage pour obtenir une estimation de la réception DAB+ et FM.

L'estimation s'appuie sur :
- le relief et les bâtiments de l'IGN (Géoplateforme, `data.geopf.fr`) ;
- les émetteurs déclarés à l'ANFR ([données sur les installations radioélectriques de plus de 5 W](https://www.data.gouv.fr/datasets/donnees-sur-les-installations-radioelectriques-de-plus-de-5-watts-1)), embarqués dans la page.

Cartographie : [MapLibre GL](https://maplibre.org/) et [Carte facile](https://fab-geocommuns.github.io/carte-facile-site/).

## Utilisation

Ouvrez `index.html` dans un navigateur, ou servez le dossier en statique (GitHub Pages, par exemple).
L'adresse et l'étage sont repris dans l'URL (`?adresse=…&etage=…`), ce qui permet de partager un résultat.
